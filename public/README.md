# Imágenes del sitio

Para reemplazar la **imagen del Hero** (la de portada), guarda tu foto aquí con el nombre exacto:

```
public/hero.jpg
```

Recomendaciones:
- Resolución mínima: 1920×1080 px (idealmente 2400 px de ancho)
- Formato: `.jpg` (también acepta `.jpeg`)
- Peso: <500 KB para que cargue rápido (puedes optimizar en https://squoosh.app)

Si el archivo no existe, el sitio cae automáticamente a una imagen de Medellín en Unsplash.

Para reemplazar otras fotos (tours, galería, etc.) edita las URLs en:
```
src/data/tours.js
```
